# Contributing to hello-world

Thanks for your interest in contributing!

## Prerequisites

- A GitHub account
- Git installed locally

## Local setup

1. Fork the repository (if you don’t have write access).
2. Clone your fork:
   - `git clone https://github.com/<your-username>/hello-world.git`
3. Enter the project directory:
   - `cd hello-world`
4. Create a branch for your change:
   - `git checkout -b my-change`

## Running tests

This repository currently does not have a test suite configured.

If you add tests in your contribution, include clear instructions in the PR description for how to run them.

## Pull request checklist

Before opening a pull request, please make sure you have:

- [ ] Kept the change small and focused
- [ ] Updated documentation where relevant
- [ ] Written a clear PR title and description
- [ ] Linked related issues (if any)

## Pull request process

1. Push your branch to your fork.
2. Open a pull request against this repository.
3. Respond to feedback and update your PR as needed.
