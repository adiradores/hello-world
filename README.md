# hello-world

A modern, responsive welcome page built with plain HTML and CSS. No dependencies or build step required.

## GitHub Pages

Expected site URL after publishing: https://adiradores.github.io/hello-world/

To enable publishing:

1. Open [Settings → Pages](https://github.com/adiradores/hello-world/settings/pages).
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select **main** and **/ (root)**, then click **Save**.
4. Wait for the Pages deployment to finish. Future pushes to `main` publish automatically.

See the [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) for details.

## Local preview

Open `index.html` in your browser. The site uses relative asset paths so it works both locally and under the `/hello-world/` project path.
